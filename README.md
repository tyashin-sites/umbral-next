# Umbral — demonstration house (Tyashin × Thridify)

Next.js 16 App Router site on Cloudflare Workers via OpenNext, managed by Tyashin
(project `doors-website`, account doorswindows@thridify.com). Push to `main` deploys.

- Brand: `docs/BRAND.md` · Design spec: `docs/DESIGN-SPEC.md` · Asset debt: `docs/ASSET-DEBT.md`
- Products: `src/data/collection.ts` (one source for pages, sitemap, knowledge graph)
- 3D experiences: Thridify, account doorswindows@thridify.com; build notes in `docs/experiences/`

```bash
npm install && npm run build && npm start
```
